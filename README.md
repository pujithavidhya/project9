# PROJECT 9 – TUPLE-BASED PRODUCT CATALOGUE AUDIT

## About the Project

The Tuple-Based Product Catalogue Audit project is designed to manage and analyze product information stored using Python tuples. It checks product details such as product ID, product name, price, and stock availability. It helps identify products with low stock, analyze product prices, and generate a simple product catalogue report.

## Technologies Used

- **Python** – Used to develop the product catalogue program.
- **Tuples** – Used to store product details.
- **Lists** – Used to organize multiple product records.
- **Loops** – Used to process product information.
- **Conditional Statements** – Used to check stock availability and product prices.
- **Built-in Functions** – Used to find minimum, maximum, and other product details.

## Main Features

- Stores product details using tuples.
- Maintains product ID, name, price, and stock quantity.
- Displays all products in the catalogue.
- Identifies products with low stock.
- Finds the highest and lowest-priced products.
- Calculates the total value of available stock.
- Generates a product catalogue audit report.

## Algorithm

1. Start the program.
2. Create a list to store product records.
3. Store product details using tuples.
4. Display all product records.
5. Traverse the product list using a loop.
6. Check the stock quantity of each product.
7. Identify products with low stock.
8. Find the highest and lowest product prices.
9. Calculate the total inventory value.
10. Display the product catalogue audit report.
11. Stop the program.
